Place folder pictures here, named after a system folder or full system title:
GBA.png, Game Boy Advance.jpg, PS.png, PlayStation.png.
Names are case-insensitive. PNG, JPG, JPEG and ordinary BMP are supported.
Game pictures come from the stock ROM folder's Imgs directory, for example
Roms/GBA/Imgs/Golden Sun.gba.png. Folder Art is for system/folder pictures.
Images retain their aspect ratio. Borders adapt to the displayed size.

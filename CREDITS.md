# Credits

**DS Style — FrankieT19.** The design, bitmap font, themes, sounds and adapted interface code come from the DS Style GBA project. Its [Omega](https://github.com/FrankieT19/omega-ds-style-kernel) and [Omega DE](https://github.com/FrankieT19/omega-de-ds-style-kernel) roots build on **EZ-FLASH** and **Sterophonick's SimpleLight**. The RG SP frontend carries over title handling and Snake rules/geometry as well as the visual assets; it does not include a GBA cartridge kernel binary.

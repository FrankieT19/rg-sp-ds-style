# Contributing

Please open an issue before substantial changes. Small fixes, translations and reproducible bug reports are welcome.

Preserve the DS Style appearance and the stock OS's ownership of emulator configuration, saves and hardware state. Do not add fixed core choices or personal paths. Keep assets editable and retain their source attribution. Translation changes belong in `source/locale.json`; regenerate the header using the locale tool.

Follow [BUILDING.md](docs/BUILDING.md) and run checks relevant to your change. Say which firmware and device you tested, and distinguish host checks from actual hardware results. Never include ROMs, BIOS files, private firmware dumps, tokens or your runtime state in a contribution.
